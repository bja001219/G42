# G42 고스톱(2인 맞고) 룰 사양서

> **목적**: `lib/games/gostop/` 룰 엔진 구현의 **계약서**.
> 기준: **2인 맞고**, 피망/넷마블 모바일 맞고 관례. 자료 간 갈리는 부분은 "변형 있음"으로 표시하고 G42 표준을 굵게 명시.
> 검증: 화투 48장 구성·고도리·홍청초단·쌍피는 표준 데이터로 확정(2026-06, 도메인 지식 + 교차 검증). 소형 요약 모델의 위키 환각(고도리=7월, 홍단=1/3/5월 등)은 채택하지 않음.

### 1.1 분류별 정리
- **광(5장)**: 1·3·8·11·12월. **비광 = 12월**.
- **열끗(9장)**: 2·4·5·6·7·8·9·10·12월.
  - **고도리(새 3장)**: 2월(매조)·4월(흑싸리)·8월(공산 기러기).
  - **국진(9월)**: 열끗으로도, **쌍피로도** 사용 가능 → 점수 낼 때 **유리한 쪽으로 자동 배정**.
- **띠(10장)**: 홍·청·초단 9장 + 12월 비띠 1장.
  - **홍단**: 1·2·3월
  - **청단**: 6·9·10월
  - **초단**: 4·5·7월
- **피(24장)**: 나머지. 그중 **쌍피(2장 가치)** = 11월 오동 쌍피, 12월 비 쌍피, (9월 국진을 쌍피로 쓸 때).
  - *변형 있음*: 11월 쌍피는 현대 앱 표준으로 채택. 전통 덱은 11월 광+일반피3.

### 1.2 보너스패 3장
- 덱에 3장 추가. 그림은 보너스 표식.
- **G42 표준**: 보너스 3장 중 **1장 = 3피, 2장 = 쌍피(2피)**.
- 손패에 들어왔거나 더미에서 뒤집혀 나오면 **즉시 내 먹은 더미(피)로 들어가고 한 장 더 뽑는다**(턴 소모 없음). 보너스로 뒤집어 또 보너스가 나오면 반복.

## 2. 게임 진행

### 2.1 딜 (2인)
- 셔플된 51장에서: **각자 손패 10장**, **바닥 8장**, 나머지는 **더미(stock)**.
- 딜 직후 바닥에 같은 달 3장이 깔리는 등 특수 상황 처리(아래 6장 참조)는 표준 처리.

### 2.2 한 턴의 순서
1. **손패 1장 내기** → 바닥에 같은 달이 있으면 가져옴(먹기). 없으면 바닥에 놓임.
2. **더미 1장 뒤집기** → 바닥에 같은 달이 있으면 가져옴. 없으면 바닥에 놓임.
3. 먹은 카드는 분류별로 내 더미에 쌓임.
4. 매칭 과정에서 특수 이벤트(뻑/따닥/쪽/쓸기 등) 판정.
5. 점수가 7점 이상이 되면 **고/스톱** 선택. 아니면 차례를 상대에게 넘김.

### 2.3 같은 달 매칭 규칙
- 바닥에 같은 달이 **1장** → 그 1장과 함께 가져옴(쌍 먹기).
- 바닥에 같은 달이 **2장** → 내가 같은 달 1장을 내면 **3장이 모여 못 먹고 그대로 바닥에 쌓인다(=뻑)**. 4번째 카드를 내는 사람이 4장 모두 가져간다. (4.1 뻑 참조.)
  - **단**, 같은 턴 더미 뒤집기에서 그 달의 **4번째 카드**가 나오면 본인이 4장 모두 가져간다(=**자뻑**, 4.1 참조).
- 바닥에 같은 달이 **3장** → 한 번에 3장 + 낸 1장 = 4장 모두 가져옴(총통성 처리, 아래 참조).

> **G42 표준 결정(모순 제거)**: 일부 자료는 "바닥 2장일 때 1장만 골라 먹기"나 "따닥(3장 가져가기)"으로 처리하나, G42는 **표준 맞고 관례에 따라 바닥 2장 + 손패 1장 = 뻑(쌓임)**으로 일원화한다. **따닥**은 한 턴에 **서로 다른 두 페어를 각각 먹는** 경우로 재정의한다(4.1 참조).

## 3. 점수 계산

기본 점수는 각 항목을 **합산**한다.

### 3.1 광
| 구성 | 점수 |
|------|------|
| 3광 | 3점 |
| **비광 포함 3광** | **2점** |
| 4광 | 4점 |
| 5광 | 15점 |
- 2광 이하 = 0점.

### 3.2 띠
- 띠 **5장 = 1점**, 이후 1장당 +1점.
- **홍단 = 3점**, **청단 = 3점**, **초단 = 3점** (세트별 별도 가산, 장수 점수와 **합산**).

### 3.3 열끗(동물)
- 열끗 **5장 = 1점**, 이후 1장당 +1점.
- **고도리(2·4·8월 새 3장) = 5점** (별도 가산).
- 국진(9월): 열끗 또는 쌍피 중 **점수 최대가 되는 쪽으로 자동**.

### 3.4 피
- 피 **10장 = 1점**, 이후 1장당 +1점.
- **쌍피 = 2장**, **3피(보너스) = 3장**으로 카운트.

### 3.5 (미적용) 멍따/멍텅구리
- 열끗 7장 보너스(멍따)는 **G42 미적용**(주로 3인 룰).

## 4. 특수 플레이

### 4.1 바닥/더미 관련
- **뻑**: **3장이 모이면 못 먹고 그대로 바닥에 쌓인다**. 두 가지 경로:
  - (a) 바닥에 같은 달 **2장**이 있는데 내가 손패로 같은 달 1장을 냄 → 3장이 모여 못 먹음.
  - (b) 바닥에 같은 달 **1장**이 있어 손패로 쌍을 먹으려는데, 같은 턴 **더미 뒤집기가 같은 달**이라 3장이 모임 → 못 먹음(손패가 잠정 먹은 쌍도 바닥으로 되돌림).
  - 나중에 그 달의 4번째 카드를 내는 사람이 **3+1 = 4장 모두** 가져간다.
  - **자뻑**: **이번 턴 손패로 만든 뻑(위 a 경로, 바닥 2장 + 손패 1장 = 3장)을 같은 턴 더미 카드(그 달의 4번째)로 본인이 해소(4장 모두 가져감)** → 보너스(**상대 피 1장 뺏기**). 즉 바닥 2장 + 손패 1장 + 더미 1장 = 4장을 본인이 한 턴에 전부 획득.
  - **첫뻑**: 첫 턴에 뻑 → 표식(앱에 따라 보너스). **G42**: 표시만, 추가 점수 없음(*변형 있음*).
  - **연뻑/3뻑**: 한 사람이 한 판에 뻑 3번 → 즉시 그 판 패(또는 큰 페널티). **G42 표준**: 3뻑 시 **상대 즉시 승**(*변형 있음*, 옵션화). 엔진은 플레이어별 뻑 횟수를 `state.ppeokCount`에 누적하고, 3 도달 시 상대 승을 알리는 헬퍼를 제공한다.
- **따닥**: 한 턴에 **서로 다른 두 페어를 각각 먹는** 경우 — 손패 카드가 바닥의 한 달 1장과 매칭(쌍 먹기)되고, **같은 턴 더미 뒤집기가 다른 달의 바닥 1장과 매칭(또 쌍 먹기)** → 두 쌍을 모두 가져감 → **상대 피 1장 뺏기**.
- **쪽**: 바닥에 같은 달이 **없어** 손패 1장을 바닥에 놓았는데, **더미에서 뒤집은 카드가 방금 낸 카드와 같은 달**이라 둘 다 가져감 → **상대 피 1장 뺏기**.
- **쓸기/싹쓸이**: 한 턴 처리 후 **바닥이 완전히 비면** → **상대 피 1장 뺏기**.

> **상대 피 뺏기 규칙**: 상대의 **피 더미에서 1장**(쌍피보다 일반 피 우선)을 가져와 내 피에 더한다. 상대 피가 없으면 패스.

### 4.2 손패(같은 달 보유) 관련
- **흔들기**: 손패에 **같은 달 3장**이 있으면, 그 달을 처음 낼 때 **흔들기 선언** 가능 → **그 판 최종 점수 ×2**. (선언/표시 필수)
- **폭탄**: 손패에 **같은 달 3장**을 바닥의 같은 달 1장에 **한 번에 몰아 내기** → 4장 먹고 **추가 턴 + 상대 피 1장 뺏기**. 폭탄으로 낸 뒤 손이 비는 만큼 더미에서 보충(앱별). **G42**: 폭탄 시 그 달 4장 획득 + 1회 추가 진행 + 상대 피 1장.
- **총통(촌)**: 딜 직후 **손패에 같은 달 4장**이 다 들어오면 → **즉시 그 판 승리**(또는 큰 점수). **G42 표준**: **즉시 승**, 점수는 기본 +α(아래 8장 예시). 바닥 총통(바닥 같은 달 4장)도 처리.

## 5. 고(Go) / 스톱(Stop)

- 점수가 **7점 이상**이 되면 턴 종료 시 **고/스톱** 선택.
  - **스톱**: 그 판을 끝내고 점수 확정 → 승리.
  - **고**: 계속 진행. 단 이후 **상대가 먼저 7점 내고 스톱하면 고를 부른 쪽이 짐(고박, 6장)**.
- **고 보너스** (선택: 1·2고 +1점, 3고부터 ×2):
  - 1고: 최종에 **+1점**
  - 2고: 최종에 **+2점**(누적)
  - 3고부터: 직전 합계에 **×2**씩 (3고 ×2, 4고 ×4, 5고 ×8 …)
  - 식: `(base + min(고수,2)) × 2^max(0, 고수-2)`

## 6. 박 (배수 페널티)

이긴 사람의 점수를 곱한다. **G42 채택: 고박/독박, 피박, 광박** (멍박 미적용).

- **피박**: 이긴 사람이 **피로 점수를 냈는데** 진 사람의 피가 **7장 미만**이면 → **×2**. (*변형 있음*: 5장 이하 기준도 존재. G42 = 7장 미만)
- **광박**: 이긴 사람이 **광으로 점수를 냈는데** 진 사람의 광이 **0장**이면 → **×2**.
- **고박/독박**: 진 사람이 그 판에 **고를 외친 적이 있는데** 결국 졌다면 → **×2** (고를 부른 쪽이 독박을 씀).

> 2인·점수누적 게임 적응: 돈 판돈이 없으므로 "독박"은 **이긴 사람의 획득 점수를 ×2**로 반영한다(고를 부른 쪽의 손해를 점수로 환산).

---

## 7. 나가리 (무승부)

- **발동**: 더미와 양쪽 손패가 모두 소진되도록 **아무도 7점 내고 스톱하지 못함**.
- **처리**: 점수 변동 없음. **다음 판 최종 점수 ×2** 누적. 연속 나가리면 ×4, ×8…
- 선(先)은 유지.

## 8. 배수 적용 순서 & 예시

**적용 순서**:
```
최종점수 = (기본점수 합) [+ 고 보너스 가산/배수]
                       × 흔들기(×2/회)
                       × 폭탄(×2/회, 채택 시)
                       × 나가리누적(×2/회)
                       × 피박(×2) × 광박(×2) × 고박(×2)
```
- 기본점수에 먼저 고 보너스 공식을 적용 → 그 결과에 흔들기/폭탄/나가리/박 배수를 차례로 곱한다.

**예시 1**: 비광 없는 3광(3점) + 홍단(3점) + 피 12장(3점) = **기본 9점**. 1고 외치고 스톱 → `(9 + 1) = 10점`. 상대 피 6장(7 미만) → 피박 ×2 → **20점** 획득.

**예시 2**: 기본 7점에서 3고까지 부름 → `(7 + 2) × 2^(3-2) = 9 × 2 = 18점`. 흔들기 1회 있었으면 ×2 → **36점**. 상대가 그 사이 고를 부른 적 없으면 고박 미적용.

## 9. 점수 누적 / 저장 (G42)

- 돈 개념 없음. 매 판 **위 최종 점수**(모든 배수 반영)를 **이긴 사람 통산 누적에 가산**.
- 저장 단위: **플레이어별 통산**(누적점/승/패/나가리) + **둘의 head-to-head 전적**.
- 저장소: 온라인 = Firestore `profiles/{playerId}`, `headtohead/{pairKey}`. 로컬/핫시트 = `shared_preferences`.

---

## 10. 선(先) / 판 진행

- **첫 판**: 무작위로 선 지정.
- **이후**: **직전 판 이긴 사람이 다음 선**. 나가리면 선 유지.
- 매 판: 딜 → 진행 → 스톱/나가리 → 점수 정산 → 누적 저장 → 다음 판.

## 11. 동기화/구현 제약 (GAME_CONTRACT 준수)

- `state`는 통째로 제출. **중첩 배열 금지** → 카드는 정수 ID(0~50) 또는 문자열로 인코딩, 손패/바닥/더미/먹은패는 **평탄 List**.
- 카드 인코딩: `cardId = (month-1)*4 + indexInMonth` (0~47), 보너스패 = 48·49·50.
- 손패는 `state`에 플레이어별 Map으로(`hands: {playerId: [ids]}`), UI에서 상대 손패는 **뒷면**으로 가림(온라인) / 핫시트는 가림막.
- 턴 게이팅: 입력 핸들러 맨 앞 `if (!session.isMyTurn(room)) return;`
